# TECHNICAL SPEC: PLANAR TRANSITIONS

## 1. SENSORY RULES (VISION)
- **Sky → Surface**: Full vision.
- **Surface → Mantle**: Zero vision into tunnels unless standing on an entrance.
- **Mantle → Anywhere**: Zero vision outside the Subterranean layer.

## 2. TRANSITIONS
- **Natural (The Only Way)**: 
    - **Surface ↔ Sky (L0 ↔ L1)**: Units must use "High Peaks" to transition between these layers.
    - **Surface ↔ Mantle (L0 ↔ L-1)**: Units must use "Cave Mouths" to transition between these layers.
- **Restriction**: Drop-Pods and Teleports have been removed from the simulation to emphasize chokepoint strategy.
